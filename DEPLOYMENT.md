# 🚀 Инструкции по деплою на GitHub Pages

## 📋 Предварительные требования

1. **GitHub аккаунт** - убедитесь, что у вас есть аккаунт на GitHub
2. **Репозиторий** - репозиторий должен называться `username.github.io` (где `username` - ваше имя пользователя)
3. **Права доступа** - у вас должны быть права на запись в репозиторий

## 🔧 Настройка GitHub Pages

### Шаг 1: Создание репозитория

1. Перейдите на [GitHub](https://github.com)
2. Нажмите "New repository" (зеленая кнопка)
3. Введите имя репозитория: `username.github.io` (замените `username` на ваше имя пользователя)
4. Выберите "Public"
5. Нажмите "Create repository"

### Шаг 2: Загрузка файлов

1. Клонируйте репозиторий локально:
```bash
git clone https://github.com/username/username.github.io.git
cd username.github.io
```

2. Скопируйте все файлы проекта в папку репозитория
3. Добавьте файлы в git:
```bash
git add .
git commit -m "Initial commit"
git push origin main
```

### Шаг 3: Включение GitHub Pages

1. Перейдите в репозиторий на GitHub
2. Нажмите на вкладку "Settings"
3. В левом меню найдите "Pages"
4. В разделе "Source" выберите "Deploy from a branch"
5. В поле "Branch" выберите "main" (или "master")
6. В поле "Folder" оставьте "/ (root)"
7. Нажмите "Save"

### Шаг 4: Ожидание деплоя

- GitHub автоматически начнет деплой
- Деплой может занять несколько минут
- После успешного деплоя вы увидите сообщение "Your site is published at https://username.github.io"

## 🔄 Автоматический деплой

Проект настроен с GitHub Actions для автоматического деплоя:

1. **При каждом push** в ветку `main` сайт автоматически обновляется
2. **GitHub Actions** выполняет сборку и деплой
3. **Логи деплоя** можно посмотреть во вкладке "Actions"

### Проверка статуса деплоя

1. Перейдите во вкладку "Actions" в репозитории
2. Найдите последний workflow "Deploy to GitHub Pages"
3. Нажмите на него для просмотра деталей
4. Зеленая галочка означает успешный деплой

## 🐛 Решение проблем

### Сайт не отображается

1. **Проверьте настройки Pages** в Settings → Pages
2. **Убедитесь, что репозиторий публичный**
3. **Проверьте ветку** - должна быть `main` или `master`
4. **Подождите несколько минут** - деплой может занять время

### Ошибки в GitHub Actions

1. **Проверьте логи** во вкладке Actions
2. **Убедитесь, что файлы корректны** (HTML, CSS, JS)
3. **Проверьте права доступа** - нужны права на Pages

### Проблемы с доменом

1. **Проверьте DNS настройки** (если используете кастомный домен)
2. **Убедитесь, что CNAME файл корректный**
3. **Подождите обновления DNS** (может занять до 24 часов)

## 📱 Тестирование

### Локальное тестирование

```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

### Проверка на GitHub Pages

1. Откройте https://username.github.io
2. Проверьте все страницы
3. Протестируйте функциональность
4. Проверьте на мобильных устройствах

## 🔍 SEO и производительность

### Проверка SEO

1. **Google PageSpeed Insights** - проверьте скорость загрузки
2. **Google Search Console** - добавьте сайт для мониторинга
3. **Meta теги** - убедитесь, что все meta теги корректны

### Оптимизация

1. **Сжатие изображений** - используйте WebP формат
2. **Минификация CSS/JS** - для продакшена
3. **Кэширование** - настройте заголовки кэширования
