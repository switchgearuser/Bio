# 🤝 Руководство по вкладу в проект

Спасибо, что вы заинтересованы в улучшении проекта! Мы приветствуем любой вклад от сообщества.

## 📋 Как внести вклад

### 🐛 Сообщение об ошибках

1. **Проверьте существующие Issues** - возможно, ваша проблема уже известна
2. **Создайте новый Issue** используя шаблон "Сообщение об ошибке"
3. **Опишите проблему** максимально подробно
4. **Приложите скриншоты** если это поможет понять проблему

### 💡 Предложения новых функций

1. **Создайте Issue** используя шаблон "Предложение новой функции"
2. **Опишите проблему** которую решает функция
3. **Предложите решение** с конкретными деталями
4. **Укажите приоритет** функции

### 🔧 Внесение изменений в код

1. **Форкните репозиторий**
2. **Создайте ветку** для ваших изменений:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Внесите изменения** следуя стандартам кода
4. **Протестируйте** ваши изменения
5. **Создайте Pull Request**

## 🎯 Стандарты кода

### HTML
- Используйте семантические теги
- Добавляйте атрибуты `alt` для изображений
- Следуйте стандартам доступности (WCAG)

### CSS
- Используйте CSS переменные для цветов и размеров
- Следуйте принципу мобильного первого
- Добавляйте комментарии для сложных селекторов

### JavaScript
- Используйте современный ES6+ синтаксис
- Добавляйте комментарии для сложной логики
- Обрабатывайте ошибки gracefully

### Общие принципы
- Пишите читаемый код
- Добавляйте комментарии где необходимо
- Следуйте принципу DRY (Don't Repeat Yourself)

## 🚀 Процесс разработки

### 1. Подготовка окружения

```bash
# Клонируйте ваш форк
git clone https://github.com/your-username/switchgearuser.github.io.git
cd switchgearuser.github.io

# Установите зависимости
npm install

# Запустите локальный сервер
npm run dev
```

### 2. Внесение изменений

- Работайте в отдельной ветке
- Делайте частые коммиты с понятными сообщениями
- Тестируйте изменения в разных браузерах

### 3. Тестирование

```bash
# Проверка HTML
npm run lint:html

# Проверка CSS
npm run lint:css

# Проверка JavaScript
npm run lint:js

# Запуск всех проверок
npm run lint
```

### 4. Создание Pull Request

1. **Обновите вашу ветку** с последними изменениями из main
2. **Создайте Pull Request** с описанием изменений
3. **Дождитесь проверки** CI/CD
4. **Ответьте на комментарии** ревьюера

## 📝 Сообщения коммитов

Используйте понятные сообщения коммитов:

```
feat: добавить темную тему
fix: исправить ошибку в мобильной версии
docs: обновить README
style: улучшить отступы в CSS
refactor: переписать функцию переключения темы
test: добавить тесты для JavaScript
```

## 🔍 Ревью кода

Все Pull Request проходят ревью кода. Мы стремимся:

- **Быстро отвечать** на PR (в течение 48 часов)
- **Давать конструктивную обратную связь**
- **Помогать** с исправлением замечаний
- **Признавать** хорошую работу
