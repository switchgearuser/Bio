# 🚀 switchgearuser - GitHub Profile

Персональная страница-портфолио разработчика, созданная для GitHub Pages.

## ✨ Особенности

- 🌙 Темная/светлая тема с автоматическим переключением
- 📱 Адаптивный дизайн для всех устройств
- 🎨 Современный и минималистичный интерфейс
- ⚡ Быстрая загрузка без зависимостей
- 🔍 SEO оптимизированная

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Стили**: CSS Grid, Flexbox, CSS Variables
- **Иконки**: Font Awesome 6
- **Хостинг**: GitHub Pages

## 🚀 Установка и запуск

### Локальная разработка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/switchgearuser/switchgearuser.github.io.git
cd switchgearuser.github.io
```

2. Откройте `index.html` в браузере или используйте локальный сервер:
```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```

3. Откройте http://localhost:8000 в браузере

### Деплой на GitHub Pages

1. Убедитесь, что репозиторий называется `username.github.io`
2. Перейдите в Settings → Pages
3. Выберите Source: "Deploy from a branch"
4. Выберите Branch: "main" и папку "/ (root)"
5. Нажмите Save
